# QuizApp

A simple and engaging Quiz Application built with **React Native**. This app allows users to test their knowledge with multiple-choice questions and get immediate feedback on their answers.

## ✨ Features

- 📱 Cross-platform mobile support (iOS & Android)
- ❓ Multiple-choice quiz questions
- ✅ Instant feedback on answers
- 🧠 Score tracking
- 🔁 Restart quiz functionality
- 💅 Clean and minimal UI

## 🛠️ Tech Stack

- **React Native**
- **JavaScript**
- **React Navigation**

## 🚀 Getting Started

### Prerequisites

- Node.js & npm/yarn installed
- React Native CLI or Expo CLI
- Android Studio / Xcode (for running on emulator or physical device)

### Installation

```bash
git clone https://github.com/emreklc28/QuizApp.git
cd QuizApp
npm install
# or
yarn install
